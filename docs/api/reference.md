# Public API reference (v1)

Every route of the public API at `/public/v1`, with the scope it needs, its parameters, its body and an example of each answer. The page is
made from the OpenAPI 3.1 document [`openapi.v1.json`](openapi.v1.json), which the BFF generates from its controllers ([ADR 0033](../adr/0033-public-api-tokens-and-webhooks.md)); load
that file into any OpenAPI tool to make a client. How to get a token and make the first call: [The public API](../api.md).
